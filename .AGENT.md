# Orange Quant Agent Guide

## Project Overview

Orange Quant is a reinforcement-learning quantitative trading framework:
- **No qlib** — data comes straight from the feeds (Tencent for A-shares,
  Binance REST / Hyperliquid ccxt for crypto) into per-symbol CSVs.
- **Single research paradigm** — daily tier-rotation RL (MultiDiscrete PPO on
  tianshou 0.4.10), shared across markets; differences live only in data hooks,
  universe selection, benchmark, and the broker.
- **Crypto live trading** — `live.py` + `server.py` execute the trained policy
  daily through Binance/Hyperliquid brokers (paper or real).

## Key Architecture

```
orange_quant/
├── data/          tencent.py (A-share fetch) · universe.py (liquidity freeze)
│                  sources.py (Binance/Hyperliquid hooks) · pipeline.py (incremental download)
├── rl/            dataset.py (bars→factors→npz) · env.py (RotationEnv)
│                  network.py/policy.py (MultiDiscrete PPO) · train.py · backtest.py · metrics.py
├── trading/       broker.py (ABC) · binance_broker.py · hyperliquid_broker.py · paper_broker.py
├── live.py        daily runner: bars → features → policy → tiers → orders (idempotent)
├── server.py      cron loop (--config/--once/--dry-run, heartbeat for Docker HEALTHCHECK)
└── config/        one yaml per market (csi300/binance/hyperliquid -rl-rotation)
```

Critical invariants:
- **No look-ahead**: universe frozen before training (liquidity from local CSVs
  over a pre-train window); z-score fit on train only; obs ≤ today's close;
  rewards use next-day data only.
- **hfq only**: never use qfq as an investment series (re-anchored by dividends
  = look-ahead).
- **Tencent pagination**: the API returns a trailing 640-row window anchored at
  the request's end date — always fetch with `end` moving backwards.
- **tianshou 0.4.10 quirks**: `DummyVectorEnv.action_space` is a per-env list
  (`[0]`); `ReplayBuffer.sample` returns `(Batch, indices)`; `policy.update`
  returns a dict only. `gym` is pinned to 0.26.2.
- **mlflow**: requires `MLFLOW_ALLOW_FILE_STORE=true` (file store blocked by
  default in 3.x).

## Commands

### Setup
```bash
python3 -m venv .venv && source .venv/bin/activate
pip install -e .          # tianshou/gym==0.26.2/torch/ccxt/akshare/mlflow/...
```

### A-share research
```bash
python -m orange_quant.data.tencent --symbols-file <symbols.tsv>  # daily bars → data/cn_raw
python -m orange_quant.rl.dataset csi300-rl-rotation              # npz cache
python -m orange_quant.rl.train csi300-rl-rotation                # PPO training
python -m orange_quant.rl.backtest csi300-rl-rotation             # NAV + metrics
```

### Crypto live
```bash
python -m orange_quant.data.build --exchange binance --top 20     # bars → data/binance_raw
python -m orange_quant.rl.dataset binance-rl-rotation
python -m orange_quant.rl.train binance-rl-rotation
python -m orange_quant.server --config binance-rl-rotation --once --dry-run   # paper
python -m orange_quant.server --config binance-rl-rotation --once             # live
```

## Config Files

| Config | Market | Universe | Purpose |
|--------|--------|----------|---------|
| `csi300-rl-rotation` | A-share (Tencent) | top-50 liquid (frozen 2012) | research |
| `binance-rl-rotation` | Binance spot | top-20 | research + live |
| `hyperliquid-rl-rotation` | Hyperliquid spot | top-20 | research + live |

## Data Locations

- `data/cn_raw/` — A-share daily CSVs (Tencent hfq, gitignored)
- `data/binance_raw/` / `data/hyperliquid_raw/` — crypto daily CSVs (gitignored)
- `data/{market}-rl-rotation/` — npz feature caches + meta (z-score params)
- `data/live_state/` — idempotency state + heartbeat (gitignored)

## Environment

- Python 3.12 venv in `.venv/` (homebrew)
- API keys in `.env` (gitignored): `BINANCE_API_KEY`, `BIANCE_SECRET_KEY`,
  `HYPERLIQUID_ADDRESS`, `HYPERLIQUID_PRIVATE_KEY`
- Docker: `docker compose --profile binance-live up -d`
