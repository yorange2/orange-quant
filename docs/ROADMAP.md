# Orange Quant Roadmap：RL 数据扩充（解决"数据少"）

> 创建于 2026-08-09。上一版路线图（去 qlib 全面重构）已完成，见 `docs/finished/ROADMAP.md`。
> 本路线图针对当前 RL 策略的核心短板：**训练数据少**（横截面 9 只币 × 时序 4 年日频 ≈ 1000 训练步）。

## 当前基线（对照基准，test 2025-01-01 ~ 2026-08-01）

| 配置 | 年化 | Sharpe | 换手 | 超额 vs 等权 |
|---|---|---|---|---|
| Binance 9 只历史池（2019 冻结） | −9.2% | −0.18 | 41× | −2.9%（IR −0.02） |
| Binance 48 只当前池（含新币） | −26.6% | −0.48 | 43× | −21.9% |
| A 股 50 只池（2012 冻结） | −5.0% | −0.31 | 49× | −8.1% |

数据量现状：加密日频 2020-2023 train 段 ≈ 1000 步（9 只 × 4 年）；A 股 50 只 × 1945 天。

## 路线图（按性价比排序，可独立落地）

### R1. 小时频数据（数据量 ×24）⭐ 最高优先

**动机**：币安 7×24，小时频是日频 24 倍的数据红利，纯工程改动，无研究风险。

- [ ] `data/build.py` 支持 `--freq 1h`（`BinanceSource.fetch_hourly` 钩子仍在，未删）
- [ ] `rl/dataset.py` bar_reader 支持小时 CSV（`date,open,close,high,low,volume`，UTC 对齐）
- [ ] 小时频日历（2595 天 → ~62000 小时行），split 边界按时间戳
- [ ] env horizon 语义：120 步小时 = 5 天持仓周期（贴近真实交易粒度）
- [ ] 验证：train 快跑 5 epoch → 与日频基线对比 valid/test

**预期**：训练样本 1000 → 24000+ 步，动作空间（4⁹）不再过拟合。

### R2. 历史池扩大 + train 窗口提前（池 ×3、时序 ×1.5）

**动机**：币安 2017 年上线，BTC/ETH 有 2017 起全历史；2019 冻结只剩 9 只存活币。

- [ ] train 窗口改 `2018-01-01 ~ 2023-12-31`（6 年），冻结 `2017-12-31`
- [ ] 2017 年底存活的币 ≈ 20-30 只（候选池扩大 3 倍）
- [ ] `min_history_days` 200 → 100（多入选）
- [ ] 数据下载起点提前至 2017-01-01
- [ ] 验证：冻结名单打印、npz 重建、与 R1 组合后回测

**注意**：train 起点 2018 意味着 BTC 早期极端波动段（2017-2018 泡沫）进入训练——差分奖励（vs 等权）会吸收市场 beta，影响有限。

### R3. 特征预训练（监督学习预热 encoder）

**动机**：数据少时 RL 同时学"特征表示 + 策略"效率低；先用历史数据离线学特征表示，RL 只学策略头。

- [ ] 监督任务：用 `(feats[t], tiers[t]) → 次日收益` 训练一个小分类/回归头
- [ ] 把学到的 encoder 作为 `MultiDiscreteActor`/`RotationCritic` 的共享 body 初始化
- [ ] RL 训练时 body 冻结或低学习率微调
- [ ] 验证：预训练 loss 收敛、RL 训练收敛速度（epochs-to-best）对比

**预期**：收敛快数倍、valid 方差降低（常见于小样本 RL）。

### R4. 多市场联合训练

**动机**：`orange_quant.rl` 市场无关——A 股（横截面几百只）+ 加密（波动/趋势多样性）共享网络。

- [ ] 多市场数据集联合：各市场特征独立 z-score，动作空间 = 各市场自己的 top-N
- [ ] 训练时每个 epoch 交替采样不同市场的 env（或拼接 batch）
- [ ] A 股提供横截面多样性、加密提供高波动样本
- [ ] 验证：联合训练模型 vs 单市场模型的 valid/test 对比

### R5. 数据增强

- [ ] **episode 重叠采样**：train 段随机起点改为"起点间隔 5-10 天"的重叠采样（有效样本 ×3-5）
- [ ] **obs 噪声增强**：训练时对 obs 加 σ≈0.05 高斯噪声（提高对价格噪声鲁棒性）
- [ ] 验证：A/B 对比 valid 波动

### R6. walk-forward 滚动重训

**动机**：一次性 4 年训练 vs 测试窗口分布漂移（test 熊市段差的根因之一）。

- [ ] 每季度滚动窗口：train = 过去 3 年，重训 + 回测下一季度
- [ ] 输出滚动 OOS 汇总（年化/超额/换手）
- [ ] 验证：滚动 OOS 曲线 vs 单次训练

## 实施顺序建议

```
R1（小时频，纯工程）→ R2（池扩大，纯工程）→ 两者组合复测基线
→ R3（特征预训练，研究）→ R4/R5/R6（按兴趣与时间取舍）
```

R1+R2 完成后重新评估（数据量 24×3=72 倍量级），若仍有明显短板再上 R3。
